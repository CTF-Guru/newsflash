Check Point SmartConsole auth bypass exploited

VulnerabilitiesActively exploited / KEVSecurity, Network/IT Ops

Check Point patched CVE-2026-16232 (CVSS 9.3), an authentication bypass in the SmartConsole / Security Management login that lets an unauthenticated attacker obtain an admin login token and rewrite firewall policy. Jul 15, 2026Important

VulnerabilitiesAudit nowDevelopers, AppSec, Platform teams
